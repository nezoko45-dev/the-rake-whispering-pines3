# The Rake — Whispering Pines 2D

A 2D browser survival game inspired by Whispering Pines.

## Controls
- WASD / Arrow Keys — move

## Rake AI
- Within 45 studs: speed 19
- Outside 45 studs: speed 7 and searches the map instead of instantly detecting the player
- Near a bush: hides for 20 seconds
- After a lunge: chases before hiding/searching again
- Day: retreats to its initial spawn
- Day lasts 150 seconds
- Night lasts 450 seconds
